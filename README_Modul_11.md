## Ringkasan Tahap

| Tahap | Judul | Isi singkat |
|-------|-------|-------------|
| 1 | Eksplorasi Perkembangan dan Kelengkapan DBMS | Perkembangan dan fitur DBMS, perbandingan MySQL, MongoDB, dan PostgreSQL |
| 2 | Mengenal Basis Data Berorientasi Objek | Konsep objek, perbedaan relasional dan berorientasi objek, pengenalan JSON |
| 3 | Implementasi Basis Data dengan Fitur JSON | Tabel dengan kolom JSON, membaca, mengubah, menambah, menghapus, dan mencari atribut |
| 4 | Pemodelan Data Berorientasi Objek | Objek Tanaman dan inheritance, pemetaan objek ke tabel relasional |
| 5 | Analisis Lingkup Penerapan Basis Data | Analisis pemilihan DBMS dan integrasi dengan proyek |
| 6 | Manajemen Proyek dengan Git | Struktur folder proyek dan pengelolaan versi dengan Git |
| Post-test | Lembar Kerja Post-Test | Perbandingan DBMS, implementasi JSON, pemodelan objek, dan analisis bidang penerapan |
